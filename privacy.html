개인정보처리방침

Classroom Agent · 시행일 2026년 11월 11일

Classroom Agent는 만든 사람 본인만 쓰는 개인용 도구입니다. 이 방침은 앱이 Google 계정의 정보를 어떻게 다루는지 설명합니다.

읽는 정보

  • Google 캘린더: 사용자 본인 캘린더의 일정 (읽기, 새 일정 등록)
  • Google 드라이브·클래스룸: 사용자 본인 계정으로 볼 수 있는 회의 자료와 공지 (읽기 전용)

쓰는 목적

읽은 정보는 일정을 캘린더에 등록하고 사용자 본인에게 알리는 데에만 씁니다. 광고, 분석, 다른 용도로 쓰지 않습니다.

보관과 공유

  • 정보는 사용자 본인의 컴퓨터에서 처리하고, 그 컴퓨터에만 보관합니다.
  • 알림은 메신저(텔레그램)를 거쳐 사용자 본인에게만 보냅니다.
  • 어떤 정보도 다른 사람이나 회사에 팔거나 넘기지 않습니다.
  • 사용자 본인 말고는 누구도 정보를 보지 않습니다. AI 모델 학습에도 쓰지 않습니다.

Google API 정보의 사용 제한

Classroom Agent가 Google API에서 받은 정보를 쓰고 다른 앱으로 넘기는 일은 Google API 서비스 사용자 데이터 정책과 그 안의 제한적 사용(Limited Use) 요건을 따릅니다.

지우기와 연결 끊기

사용자는 언제든 Google 계정의 연결된 앱에서 Classroom Agent의 접근을 끊을 수 있습니다. 끊으면 앱은 더 이상 정보를 읽지 못합니다. 컴퓨터에 남은 기록은 사용자가 직접 지울 수 있습니다.

English summary

Classroom Agent is a personal tool used only by its author. It reads the owner's Google Calendar (read and add events) and, read-only, meeting documents in the owner's Google Drive and Classroom. Data is processed and stored only on the owner's own computer, is used only to add events to the owner's calendar and notify the owner (notifications are delivered only to the owner, through the Telegram messaging app), and is never sold, shared, or used to train AI models. Classroom Agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time in the Google Account's connected apps.
